No IUCN Red List API token was used: these are not answers of the IUCN to this package. They are
the bodies of answers the IUCN's API v4 gave on 2024-09-18 to the R client rredlist (ropensci), as
recorded in its public test fixtures (github.com/ropensci/rredlist, tests/fixtures: rl_sis.yml,
rl_species.yml, rl_assessment.yml; MIT licence, "rredlist authors"), kept here unchanged as the
shape of the API's answers: the gorilla's taxon (SIS 9404) by id and by name, and the Atlantic
Puffin's Europe assessment (166290968). Their data are the IUCN's (see the README's terms).
